## Cómo correrlos

Requisitos: Python 3 y `pip install numpy pillow notebook`.

**Leo** (desde la carpeta `Leo_codigo`):
```
cd Leo_codigo
python vanGogh.py
```

**Angie** (desde la raíz del repositorio, porque la ruta de la imagen es `Angie_codigo/vanGogh2.jpeg`):
```
jupyter notebook "pincelada y randomizer.ipynb"
```
Luego ejecuta las celdas en orden (*Run All*).
